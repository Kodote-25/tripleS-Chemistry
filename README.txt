# 트리플에스 케미명 리팩터링 파일

## 파일 구성
- `index.html`: 홈페이지 구조
- `style.css`: 표, 모바일, 모달 디자인
- `script.js`: 표 자동 생성, 상세 팝업, 멤버별 나무위키 연결
- `data.js`: 멤버 24명과 케미 데이터 133개, 원본 설명 64개 반영

## 적용 방법
1. 기존 홈페이지 폴더를 백업합니다.
2. 이 파일들을 기존 `상단`, `하단`, `상징로고`, `케미 리스트` 폴더와 같은 위치에 둡니다.
3. `index.html`을 브라우저에서 열어 확인합니다.
4. 정상 작동을 확인한 뒤 GitHub 저장소에 업로드합니다.

## 원본 데이터 관련 주의
- 업로드한 스크립트에서 추출 가능한 멤버별 나무위키 주소, 케미 설명, 이미지 경로, 링크를 `data.js`와 `script.js`에 반영했습니다.
- 설명 데이터가 확인된 케미 64개에 대해 원문 설명과 이미지 경로를 보존했습니다.
- 원본에 설명이 없던 케미는 케미명 표 데이터를 유지하되 설명을 빈 문자열로 두었습니다.
- 원본 텍스트의 일부 구문은 문법이 깨져 있었으므로, 추출 가능한 내용만 데이터로 옮겼습니다. 따라서 이 파일은 원본 코드 전체를 그대로 실행하는 것이 아니라 읽을 수 있는 데이터와 기능을 새 구조로 옮긴 버전입니다.
- 이미지 파일이 실제 폴더에 존재하는지는 이 대화에 이미지 폴더가 첨부되지 않아 확인하지 못했습니다. 이미지가 안 뜨면 `data.js`의 해당 `image` 경로와 실제 파일명을 비교해 주세요.
- 케미명은 한 쌍에 여러 이름이 있을 수 있으며, 예를 들어 `열일즈 / 햄햄다즈`는 표에서 줄바꿈으로 표시됩니다.
